# Data Directory

This directory contains information about the datasets used in this project.

## Dataset Source

The gene expression dataset used in this analysis was obtained from the NCBI Gene Expression Omnibus (GEO).

- **Database:** GEO
- **Data type:** Microarray
- **Organism:** Homo sapiens

## Data Availability

Raw and processed datasets are not stored directly in this repository.

Please refer to the original GEO record for dataset access and download instructions.

## Reproducibility

The dataset can be downloaded using the R scripts provided in the `scripts/` directory.
